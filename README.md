# Cooperative Market & Services Platform

A modern, minimalist full-stack marketplace connecting customers with verified skilled trade professionals (Electricians, Plumbers, Carpenters, Painters, Cleaners, and Drivers).

## Features
- **Customer Marketplace**: Instant search and trade filtering with verified professional profiles.
- **Worker Dashboard**: Real-time earnings tracker, payout schedules, and instant availability toggle.
- **Full-Stack Integration**: Complete Python Flask backend with REST APIs for Customer and Worker authentication, booking requests, and rating workflows.

## Running Locally
```bash
# Install dependencies
pip install -r requirements.txt

# Start the Flask server
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser.

## Deployment
Configured for zero-config deployment on Vercel via `pyproject.toml` and `app.py`.
